## Use this as your own portfolio template

This website is open source. If you like the layout, structure, or style, feel free to copy it, remix it, and turn it into your own portfolio website.

A simple way to reuse it:

1. Fork or copy this repository.
2. Replace the profile photo, project images, videos, links, and text with your own work.
3. Update the colors, sections, and contact links so it feels like you.
4. Publish it with GitHub Pages from the `main` branch and repository root.

No credit is required, but it is always appreciated.

## What is included

- A single-page responsive portfolio in `index.html`
- Project cards for Roblox work
- Image and video showcase assets
- Light/dark theme support
- GitHub Pages support with `.nojekyll`
